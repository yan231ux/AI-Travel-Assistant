# 西安旅行攻略

## 1. 目的地简介

西安，古都长安，十三朝古都。中国最值得去的旅游城市之一，历史文化密度极高。必看的三大IP：兵马俑（世界第八大奇迹）、城墙（中国保存最完整的古城墙）、大雁塔（玄奘译经地）。周边还有华山（险峰）、壶口瀑布等自然景观。面食之都，便宜又好吃。春秋最佳，夏季热冬季冷。3-4天能玩透市区，加华山需要5天。

## 2. 核心景点

### 2.1 秦始皇帝陵博物院（兵马俑）
- **位置**：临潼区秦陵北路（距市区约40公里）
- **门票**：120元
- **游玩时长**：半天
- **简介**：世界第八大奇迹，三个坑都值得看。一号坑最大（千人千面的陶俑），三号坑最小但最精致。建议请讲解（106元/小时），或者跟免费讲解拼团。从西安火车站坐游5（306路）公交车直达，7元，不要坐旁边的假游5（黑车）。
- **贴士**：早上去人少，下午旅行团多到挤不动。秦始皇陵（封土堆）离兵马俑1.5公里，门票含了但没什么可看的。

### 2.2 西安城墙
- **位置**：西安市中心（有多个登城口）
- **门票**：54元
- **游玩时长**：2-3小时（骑车1小时）
- **简介**：中国保存最完整、规模最大的古城墙，全长13.7公里。强烈建议租自行车（单人45元/双人90元）骑一圈——在城墙上骑车是很独特的体验。南门（永宁门）夜景最漂亮，城墙上的灯很有氛围。也可以散步，走南门到东门这段（约5公里）。

### 2.3 大雁塔/大唐不夜城
- **位置**：雁塔区
- **门票**：大雁塔40元，登塔另收20元；大唐不夜城免费
- **游玩时长**：晚上2-3小时
- **简介**：大雁塔是玄奘为保存佛经而建，西安的标志。旁边的大唐不夜城是晚上最热闹的步行街，灯光秀+各种表演。不倒翁小姐姐就在这里。建议傍晚先去大雁塔，天黑后逛大唐不夜城。地铁大雁塔站直达。

### 2.4 陕西历史博物馆
- **位置**：雁塔区小寨东路91号
- **门票**：免费（基础馆）或30元（珍宝馆）
- **游玩时长**：2-3小时
- **简介**：中国最好的省级博物馆之一，馆藏文物极其丰富。何家村窖藏出土的金银器（珍宝馆）是必看。基础馆免费但非常难预约（提前14天蹲点抢）。抢不到可以买珍宝馆30元票，容易很多。

### 2.5 回民街/洒金桥
- **位置**：莲湖区钟楼附近
- **门票**：免费
- **游玩时长**：1-2小时
- **简介**：西安最有名的小吃街。回民街主街（北院门）游客多价格高，本地人更喜欢去旁边的洒金桥（步行10分钟）和西羊市。推荐洒金桥上的：杨天玉腊牛羊肉、老米家大雨泡馍、哈桑烤肉。避开回民街主街上的"网红"店。

### 2.6 华山（周边一日游）
- **位置**：渭南市华阴市（高铁30分钟）
- **门票**：160元（西峰索道140元，北峰索道80元）
- **游玩时长**：一天
- **简介**："奇险天下第一山"，长空栈道、鹞子翻身是刺激项目（有安全绳）。推荐路线：西峰索道上→南峰→东峰→中峰→北峰索道下，全程约6-7小时。华山北站有免费公交到游客中心。不要节假日去，人山人海。

## 3. 餐饮推荐

### 面食
- **老马家泡馍(回民街)**：西安最经典的泡馍，自己掰馍很有意思，人均30元。掰成黄豆大小才入味。
- **爱骅裤带面(东木头市)**：招牌Biangbiang面，面条像裤带一样宽，人均20元。油泼辣子香气扑鼻。
- **志亮灌汤蒸饺(回民街)**：牛肉灌汤蒸饺，汁水丰富，人均40元。配一碗八宝稀饭完美。

### 本地菜
- **长安大排档(赛格店)**：陕西菜集合店，环境好，人均80元。葫芦鸡、毛笔酥、麻将十三幺适合拍照打卡。
- **虎子水盆羊肉(翠华路总店)**：水盆羊肉（羊肉汤），配月牙饼吃，人均40元。冬天喝一碗全身暖和。

### 小吃
- **魏家凉皮(连锁)**：西安国民快餐，凉皮+肉夹馍+冰峰汽水是"三秦套餐"，人均25元。分店到处都有。
- **洒金桥**：真正的本地小吃街。推荐：杨天玉腊牛肉夹馍（15元）、马二酸汤水饺（20元）、哈桑烤肉（2元/串）。
- **陕拾叁**：西安版哈根达斯，有油泼辣子味、咸蛋黄味、醪糟味等奇葩冰淇淋，人均35元。

## 4. 住宿建议

- **钟楼/南门区域**：300-600元/晚，最方便，去哪都近
- **大雁塔区域**：400-800元/晚，靠近大唐不夜城，夜景好
- **火车站区域**：200-400元/晚，方便去兵马俑和华山

## 5. 注意事项

- 去兵马俑坐游5（306路）在西安火车站东广场上车，认准"西安公交"字样，不要坐拉客的黑车
- 陕西历史博物馆免费票极难抢，建议直接买珍宝馆30元票
- 回民街主街上的东西偏贵，隔壁洒金桥一样的东西便宜30%
- 华山建议坐西峰索道上（风景好），北峰索道下（便宜）
- 西安面食分量大，一碗面够两个人吃，点菜时注意
- 城墙骑自行车是很好的体验，但注意租车的押金（一般200元）
- 西安夏天很热（40℃+），冬季干冷（-5℃），带好对应衣物
- 从西安去华山坐高铁到"华山北站"最快（28分钟），不是"华山站"

## 6. 特殊场景贴士

### 雨天备选方案
- 西安雨季集中在夏季，多是短时阵雨，带伞即走
- 雨天优先室内：陕西历史博物馆（需预约）、西安博物院（免费）、碑林博物馆
- 兵马俑有馆棚遮挡，雨天照样能看，而且游客少、体验更好
- 大唐不夜城雨天照常开放但室外演出可能减少，改逛大雁塔北广场地下街
- 雨后城墙、钟鼓楼夜景更通透，适合补拍

### 亲子出行提示
- 西安很适合带孩子看历史：兵马俑建议请讲解，孩子才看得懂（106元/小时）
- 城墙租亲子自行车骑行一圈，孩子会记住这个体验
- 大唐不夜城的灯光表演、糖画、不倒翁是孩子最爱的部分
- 陕西历史博物馆免费票难抢，买珍宝馆30元票对孩子也更合适
- 西安面食分量大，给孩子点小份，泡馍、肉夹馍都受欢迎

### 省钱贴士
- 西安是性价比最高的美食城市：泡馍30元、凉皮25元、水盆羊肉40元，人均40能吃很好
- 门票是大头：兵马俑120元、华山160元+索道，看预算取舍（城墙54元可去）
- 住宿选火车站区域200-400元/晚便宜，去兵马俑、华山都方便
- 市内全程地铁+支付宝乘车码，比打车省一半

### 交通出行
- 西安地铁四通八达：大雁塔站、钟楼站、南门站直达核心景点
- 去兵马俑在火车站东广场坐游5（306路）7元直达，认准"西安公交"字样防黑车
- 去华山坐高铁到"华山北站"（28分钟），站前有免费公交到游客中心
- 城墙租自行车45元骑一圈（约1小时），是市区交通外的特色体验

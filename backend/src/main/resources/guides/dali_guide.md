# 大理旅行攻略

## 1. 目的地简介

大理在云南西部，白族聚居地，"风花雪月"（下关风、上关花、苍山雪、洱海月）是它的标志。游客来大理主要做三件事：逛古城、环洱海、爬苍山。气候四季如春，但高原紫外线强，昼夜温差大（早晚可能差10度+）。旅游分三个圈：古城（吃住集中）、洱海西线（田园风光）、洱海东线（海景公路）。适合慢节奏、拍照、发呆。

## 2. 核心景点

### 2.1 大理古城
- **位置**：大理市古城
- **门票**：免费（古城内部分小景点单独收费）
- **游玩时长**：半天到一天
- **简介**：古城不大，步行可逛完。核心街道是人民路（酒吧餐饮）、复兴路（购物）、洋人街（咖啡馆）。古城内不能通车，全靠步行或电瓶车。城墙可以上去（免费），俯瞰古城全景。
- **注意**：古城内商品溢价严重，买菜市场比景区店便宜一半。

### 2.2 洱海生态廊道
- **位置**：洱海西岸（才村/龙龛码头入口）
- **门票**：免费
- **游玩时长**：半天
- **简介**：大理最值得去的地方之一。西岸的生态廊道全程40+公里，只能步行或骑行。推荐路线：才村→磻溪村→喜洲古镇这一段最美。租电动车约80元/天。码头看日出非常漂亮（早上7点左右）。
- **贴士**：不要租那种又大又重的双人自行车，上坡累死。租电动车轻松很多。

### 2.3 崇圣寺三塔
- **位置**：大理古城北1.5公里
- **门票**：121元（含崇圣寺）
- **游玩时长**：2小时
- **简介**：大理地标，南诏国时期建造。主塔千寻塔高69米，两个小塔略矮。最佳拍摄点在大门外的三塔倒影公园（门票已含）。里面寺庙很大，不烧香的话1小时逛完。

### 2.4 喜洲古镇
- **位置**：大理古城北约18公里
- **门票**：免费
- **游玩时长**：2-3小时
- **简介**：比大理古城更原生态的白族古镇。亮点：转角楼（网红拍照点）、喜林苑（黄墙配稻田）、四方街集市。喜洲粑粑（破酥粑粑）是当地特色，推荐"酥香园"这家，10元/个。从大理古城打车约40元，电动车半小时。

### 2.5 双廊古镇
- **位置**：洱海东岸
- **门票**：免费
- **游玩时长**：半天
- **简介**：洱海东岸最出名的镇子，以海景客栈和日落闻名。杨丽萍的太阳宫/月亮宫在这里（现在对外开放，需预约）。从大理古城打车约80元，或坐景区直通车40元/人。双廊到丽江只要2.5小时车程，很多人把大理和丽江连起来玩。

### 2.6 苍山
- **位置**：大理古城西侧
- **门票**：40元（索道另算：感通索道单程70元，洗马潭索道往返300元）
- **游玩时长**：半天到一天
- **简介**：苍山有19峰18溪。普通人坐索道上去就行，推荐感通索道（便宜、人少），上去可以走玉带路（平坦，适合散步）。洗马潭索道最高（能到3900米），但价格贵、排队久。苍山顶部比大理古城低8-10°C，夏天上去也要带外套。

## 3. 餐饮推荐

### 白族菜（酸辣口味为主）
- **梅子井酒家**：大理老牌白族菜，酸辣鱼是招牌，人均90元。古城人民路，开了十几年。
- **大理董氏炒菜馆**：本地人去的多，便宜实惠，人均50元。
- **金傣苑·手抓饭(洋人街店)**：傣族风味手抓饭，适合多人分享，人均70元。

### 野生菌火锅（7-9月当季）
- **花与菌野生菌火锅(古城店)**：人均150元，菌子新鲜，汤底鲜美。吃菌子必须煮够15分钟，别着急。
- **方舟胖子·野生菌火锅(古城旗舰店)**：人均120元，性价比不错。

### 特色小吃
- **再回首凉鸡米线**：古城老字号，凉鸡米线10元/碗，夏天吃很爽。人民路上有两家。
- **大理古城北门菜市场**：早餐天堂，烧饵块、稀豆粉、破酥粑粑，人均10元吃饱。早上8-10点最热闹。
- **88号面包店**：德国人开的面包店，在人民路上，手工面包很好吃，适合买来当早餐或在洱海边野餐。

## 4. 住宿建议

### 古城内（方便，热闹）
- **兰林阁酒店**：古城内四星级，350元/晚，位置好，服务稳定。
- **大理邻步客栈**：古城中心，180元/晚，性价比高，房间简单但干净。

### 洱海边（风景好，安静）
- **洱海边民宿（才村/龙龛）**：200-600元/晚，淡旺季价格差很大。才村离古城近（打车15分钟），海景房普遍比古城贵。
- **SM拾陌艺术设计师民宿(天空之境店)**：设计感强，400元/晚，在古城附近，有网红拍照点。

### 海东/双廊（看日落）
- **双廊海景客栈**：价格普遍较高（400-1500元/晚），直面洱海看日落。适合住1-2晚体验一下。

## 5. 注意事项

- 大理紫外线非常强，SPF50防晒霜是必备的，阴天也要涂，一天就能晒脱皮。
- 昼夜温差大，夏天白天30℃晚上可能18℃，带件薄外套。
- 暑期（7-8月）是雨季，可能会连续下雨，但多为阵雨。带伞。
- 大理海拔约2000米，一般不会有高反，但如果要去苍山顶（3900米）建议还是注意。
- 洱海边不要试图找什么"网红打卡点"的牌子——好看的地方都在路上，骑电动车自己发现更好。
- 大理到丽江动车2小时，很多人的路线是大理→丽江→香格里拉一路玩上去。
- 当地白族菜偏酸辣，吃不惯可以跟老板说"少辣"。

## 6. 特殊场景贴士

### 雨天备选方案
- 大理雨季（7-8月）多是阵雨，下得急停得快，带伞即走
- 雨天优先室内：大理州博物馆（免费）、崇圣寺三塔（雨天香火少更清静）
- 喜洲古镇的扎染体验坊、转角楼茶馆适合雨天慢慢待
- 古城的咖啡馆、手作店遍地都是，随便找一家就能躲雨
- 苍山雨天云雾缭绕别有味道，但索道可能停运，去前先查天气

### 亲子出行提示
- 洱海生态廊道租电动车骑行最适合家庭慢游，注意给孩子戴头盔
- 喜洲粑粑、扎染DIY孩子会很喜欢，比逛景点更开心
- 古城内不能通车，全靠步行或电瓶车，带娃节奏要慢
- 高原紫外线极强，孩子务必涂SPF50防晒，阴天也要涂
- 苍山恐高的孩子慎选索道，改在洱海边玩沙玩水更稳妥

### 省钱贴士
- 大理整体消费不高：古城小吃人均10-30元就能吃好（北门菜市场更便宜）
- 住宿选古城内客栈180-350元/晚性价比高，海景房普遍溢价
- 收费景点只有三塔（121元）是硬消费，古城、洱海、喜洲都免费
- 环洱海租电动车约80元/天，比包车（300+）省太多

### 交通出行
- 大理站到古城打车约30-40元，或坐公交（更慢但便宜）
- 古城内禁车，靠步行或电瓶车，电瓶车包天约30元
- 去喜洲打车40元或坐巴士，电动车半小时；去双廊打车80元或直通车40元
- 环洱海推荐租电动车自由走，注意部分路段机动车限行

# 城市名旅行攻略

> 模板：复制本文件，把文件名改成 `{城市拼音}_guide.md`（如 `shanghai_guide.md`），
> 把第一行的"城市名"换成实际城市，再按小节补全内容即可。
> 系统启动时会自动扫描 guides/ 下所有 .md，提取 H1 标题作为城市名，无需改任何配置。

# 北京旅行攻略

## 1. 目的地简介

北京，中国首都，三千多年建城史。旅游资源分三大块：故宫/天坛/长城等世界遗产，胡同/四合院等老北京市井文化，以及国贸/三里屯等现代都市。四季分明，春秋最佳，夏季炎热多雨，冬季干冷但游客少。交通以地铁为主（覆盖主要景点），打车需避开早晚高峰。

## 2. 核心景点

### 2.1 故宫博物院
- **位置**：东城区景山前街4号
- **门票**：旺季60元/淡季40元（需提前在"故宫博物院"公众号预约）
- **游玩时长**：至少4小时（走马观花2小时也能逛完中轴线）
- **简介**：明清两代皇家宫殿，世界最大木结构古建筑群。建议租讲解器20元，或者跟免费人工讲解（午门入口处排队）。周一闭馆。
- **贴士**：旺季票非常难抢，提前7天晚8点放票，建议定好闹钟

### 2.2 天安门广场
- **位置**：东城区东长安街
- **门票**：免费（需携带身份证）
- **游玩时长**：30分钟-1小时
- **简介**：世界最大城市广场，周边有人民大会堂、国家博物馆、毛主席纪念堂。看升旗需早起（时间每天不同，夏季约5点左右）。安检严格，带好身份证。

### 2.3 颐和园
- **位置**：海淀区新建宫门路19号
- **门票**：旺季30元/淡季20元（联票含佛香阁等另加50元）
- **游玩时长**：半天
- **简介**：中国保存最完整的皇家园林，昆明湖+万寿山布局。推荐从东宫门进，沿长廊走到石舫，再坐船到南湖岛。十七孔桥日落金光穿洞是冬季限定景观（冬至前后）。

### 2.4 八达岭长城
- **位置**：延庆区G6京藏高速58号出口
- **门票**：旺季40元/淡季35元
- **游玩时长**：半天
- **简介**：最成熟的长城段落。8775路公交从德胜门直达，或北京北站坐S2线（票价6元）。建议不要节假日去，人挤人。强烈推荐坐缆车（往返140元），爬上去太累。想人少可以去慕田峪长城。

### 2.5 天坛公园
- **位置**：东城区天坛内东里7号
- **门票**：旺季15元/淡季10元（祈年殿等核心景点另收20元）
- **游玩时长**：2小时
- **简介**：明清皇帝祭天场所。祈年殿是北京标志性建筑。早上去能看到大爷大妈踢毽子打太极，很有生活气息。联票含祈年殿、回音壁、圜丘。

## 3. 餐饮推荐

### 北京烤鸭
- **四季民福烤鸭店(王府井店)**：性价比最高之一，人均120元，烤鸭现烤，皮脆肉嫩。排队较长（1-2小时），建议11点前到。
- **大董烤鸭(工体店)**：高端版，人均300+，环境好，适合商务或特殊场合。
- **便宜坊烤鸭(鲜鱼口店)**：老字号，焖炉烤鸭，比挂炉的更不腻，人均100元。比四季民福人少。

### 老北京小吃
- **尹三豆汁(前门旗舰店)**：豆汁+焦圈+咸菜，地道北京早餐，人均15元。外地人可能喝不惯，建议先点一小碗试试。
- **方砖厂69号炸酱面(前门店)**：北京排名靠前的炸酱面，人均25元。面劲道，酱香浓。
- **护国寺小吃(护国寺总店)**：集合各种北京小吃（豌豆黄、驴打滚、艾窝窝），人均30元。适合一次尝多种。

### 其他推荐
- **胡大饭馆(簋街总店)**：麻辣小龙虾出名，人均120元。簋街整条街都是夜宵，越晚越热闹。
- **牛街清真小吃街**：北京最好的清真小吃聚集地，白记年糕、聚宝源涮肉都很出名，人均50-100元。

## 4. 住宿建议

### 经济型（200元/晚以下）
- **北京万家灯火酒店(前门店)**：靠近前门和大栅栏，位置好但房间偏小，250元/晚。
- **汉庭酒店(北京天安门广场店)**：连锁酒店品质稳定，300元/晚，靠近地铁前门站。

### 舒适型（300-600元/晚）
- **北京中关村皇冠假日酒店**：五星标准，知春路，800元/晚，适合商务或高预算游客。
- **秋果酒店(北京南锣鼓巷店)**：设计型酒店，位置极佳（南锣鼓巷里面），500元/晚，闹中取静。

### 特色住宿
- **胡同里的四合院民宿**：多家可选，集中在后海/什刹海区域，400-1000元/晚。体验老北京生活但隔音普遍差。

## 5. 注意事项

- 故宫、国博、毛主席纪念堂等都**需要提前预约**，不是到了就能进。旺季提前一周。
- 北京地铁可以用支付宝/微信扫码乘车，不需要买卡。
- 打车高峰期（早8-9点，晚6-7点）非常难打，建议地铁。
- 长城别去八达岭人挤人的话，慕田峪和司马台长城体验更好。
- 北京很多景点周一闭馆，安排行程时避开。
- 夏季高温可达40℃，注意防暑；冬季-10℃以下，注意保暖。

## 6. 特殊场景贴士

### 雨天备选方案
- 北京雨季集中在7-8月，多是短时阵雨，带伞即走
- 雨天优先室内：国家博物馆、首都博物馆（均免费需预约）、中国科技馆
- 故宫、天坛雨天反而清静、别有韵味，但石板路湿滑注意脚下
- 国家图书馆、北京坊商场适合躲雨，地铁沿线全在地下
- 注意部分露天景点（颐和园游船、长城缆车）雨天可能停运

### 亲子出行提示
- 故宫带娃建议从午门进、沿中轴线快走，避开人最多的三大殿排队区
- 中国科学技术馆、国家自然博物馆是孩子最爱，需提前预约
- 北京动物园+海洋馆在市区，半天就能玩完，票价比故宫便宜
- 长城带娃强烈建议缆车往返（140元），徒步段对小朋友太累
- 旺季务必提前预约故宫/国博，否则白跑一趟

### 省钱贴士
- 门票集中在故宫（60元）和长城（40元）两项，其余景点大多低价或免费
- 老北京小吃（豆汁、炸酱面、护国寺小吃）人均25-50元，比餐厅实惠
- 住宿选汉庭、如家等经济连锁300元/晚左右，靠近地铁即可
- 市内靠地铁刷支付宝乘车码最省，尽量避开打车（堵车又贵）

### 交通出行
- 北京地铁覆盖几乎所有景点，支付宝/微信乘车码直接扫码进站
- 早晚高峰（8-9点、18-19点）地铁比地面交通靠谱，别贪快打车
- 去八达岭长城：德胜门877路公交直达，或北京北站S2线（6元），别坐黑车
- 机场、火车站距市区远，出发前预留1小时以上通勤时间

# 三亚旅行攻略

## 1. 目的地简介

三亚位于海南岛最南端，中国最好的海滨度假城市。四大海湾各有特点：三亚湾（离市区近、看日落）、大东海（性价比高、游泳方便）、亚龙湾（沙质最好、酒店贵）、海棠湾（安静、高端酒店+免税店）。最佳季节11月-次年4月，夏季炎热潮湿且时有台风。适合家庭度假、情侣游、潜水爱好者。消费整体偏高，尤其旺季。

## 2. 核心景点

### 2.1 蜈支洲岛
- **位置**：海棠湾内
- **门票**：144元（含船票）
- **游玩时长**：一天
- **简介**：三亚最热门的外岛，海水能见度好，适合潜水和玩水上项目。岛上设施完善但消费高（矿泉水10元）。建议一早上岛，下午4点前返程。潜水项目380-880元不等，推荐珊瑚礁潜水（性价比最高）。
- **贴士**：晕船的人提前吃晕船药，浪大的时候40分钟的船程很难受。冬季风大可能停航。

### 2.2 亚龙湾
- **位置**：三亚市区以东约20公里
- **门票**：免费（沙滩部分区域被酒店占据）
- **游玩时长**：半天到一天
- **简介**：沙质最好的海湾，号称"天下第一湾"。公共沙滩在"亚龙湾海底世界"附近可以免费进入。酒店沙滩只对住客开放。水上项目（摩托艇、香蕉船等）比蜈支洲岛便宜。

### 2.3 南山文化旅游区
- **位置**：崖州区南山
- **门票**：129元
- **游玩时长**：半天
- **简介**：108米高的海上观音像很震撼，比自由女神还高。景区很大，建议坐观光车（30元）。除了观音像还有南山寺和不二法门。注意：景区内消费高，自带水和小吃。

### 2.4 鹿回头风景区
- **位置**：鹿岭路
- **门票**：42元
- **游玩时长**：2小时
- **简介**：看三亚全景和日落的最佳地点。山顶可以俯瞰整个三亚湾和市区。建议下午5点左右上山，看日落+夜景。有观光车（往返28元）不用爬。

### 2.5 三亚国际免税城
- **位置**：海棠北路118号
- **门票**：免费
- **游玩时长**：2-3小时
- **简介**：亚洲最大的单体免税店。化妆品、香水比专柜便宜15-30%。需要离岛机票/船票才能购买，提货方式：机场提货或即购即提（需担保金）。旺季排队严重，建议上午去。

## 3. 餐饮推荐

### 海鲜
- **第一市场海鲜加工**：自己去市场买海鲜（皮皮虾约80元/斤、石斑鱼60元/斤），旁边找加工店。推荐"四川小胡子海鲜"加工，加工费约20元/斤。注意称重时把袋子里的水沥干。
- **东海龙宫(大东海店)**：三亚老牌海鲜店，人均200元。环境好，价格偏贵但品质有保障。
- **下岗职工海鲜加工市场**：比第一市场更本地化，价格略低。

### 椰子鸡
- **嗲嗲的椰子鸡(椰梦长廊店)**：三亚最火的椰子鸡店之一，人均150元。三个椰青水煮一只文昌鸡，汤鲜肉嫩。

### 小吃
- **正宗抱罗粉店**：抱罗粉是海南特色，人均20元，推荐腌粉（汤少味浓）。
- **阿菊冷饮店(第一市场店)**：炒冰超级好吃，芒果炒冰15元，用新鲜水果现炒。
- **清补凉**：海南特色甜品，椰奶+各种豆类水果，街上10元左右一碗。

## 4. 住宿建议

- **大东海区域**：200-500元/晚，性价比最高，吃饭方便，离市区近
- **亚龙湾区域**：600-2000元/晚，沙质好，适合泡酒店
- **三亚湾区域**：300-800元/晚，看日落绝佳，但沙质一般
- **海棠湾区域**：800-3000元/晚，高端酒店+免税店，但风浪大不能下海

## 5. 注意事项

- 三亚紫外线极强，SPF50+防晒霜+墨镜+帽子是标配，哪怕阴天也会晒伤
- 海鲜市场买海鲜注意：看着称、袋子戳洞放水、换钱别被调包
- 出租车/网约车司机推荐的海鲜店不要去，他们有回扣，价格贵质量差
- 水上项目（潜水、摩托艇等）货比三家，酒店前台的价格通常比外面贵一倍
- 鹿回头日落大概在下午6-7点（夏季）或5-6点（冬季）
- 离岛免税：机场提货建议提前3小时到机场，旺季排队很长
- 别信路边发传单的"免费一日游"——都是购物团
- 椰梦长廊有20多公里长，适合傍晚散步或骑行

## 6. 特殊场景贴士

### 雨天备选方案
- 三亚夏季台风季多暴雨，台风天蜈支洲岛、海上项目会停航停开，务必看天气再安排
- 雨天优先室内：三亚国际免税城（全天候空调）、各大购物中心、南山寺（雨后云雾很美）
- 台风天行程务必留缓冲，暴雨通常半天就过去，别硬排户外景点
- 亚龙湾、大东海雨后浪大，注意海边安全告示，别下水
- 淡季（非春节、暑期）来三亚，天气稳定、人也少

### 亲子出行提示
- 三亚是最经典的亲子度假地，亚龙湾沙质细软最适合孩子挖沙堆堡
- 大东海浅滩平缓、游泳方便，比海棠湾安全（海棠湾浪大不宜下海）
- 蜈支洲岛潜水等水上项目有年龄限制，玩之前问清身高体重要求
- 孩子防晒第一：SPF50+防晒霜+遮阳帽，戏水后必须补涂
- 泡酒店泳池+玩沙+免税城购物，就是最省心的亲子组合

### 省钱贴士
- 海鲜去第一市场自己买（皮皮虾约80元/斤）+找加工店（约20元/斤），比大店省一半
- 住宿选大东海区域200-500元/晚性价比最高，亚龙湾、海棠湾酒店溢价明显
- 水上项目货比三家，酒店前台的价格通常比外面贵一倍
- 避开春节、暑期旺季，机票+酒店能省下大头开销

### 交通出行
- 凤凰机场到市区打车约40-60元，夜航贵一些
- 各湾区之间公交班次一般（如25路），人多建议打车或拼车
- 去蜈支洲岛从海棠湾码头乘船（约40分钟），晕船提前吃晕车药
- 离岛免税机场提货建议提前3小时到机场，旺季排队很长
